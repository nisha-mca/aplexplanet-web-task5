# ApexPlanet Task 5 - CareerHub Job Portal

A complete capstone project using only:
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Responsive home page
- Dynamic job cards
- Search by job title/company
- Location filter
- Job type filter
- Salary and company sorting
- Save/unsave jobs
- LocalStorage persistence
- Job details modal
- Demo Apply Now action
- Contact form
- Responsive mobile navigation
- Desktop/tablet/mobile layouts
- No external frameworks or libraries

## Task 5 optimization
- JavaScript loaded with `defer`
- No heavy external libraries
- Single CSS and JS assets
- Responsive CSS media queries
- Efficient dynamic rendering
- LocalStorage for saved-job persistence
- Semantic HTML and viewport metadata
- Minimal network dependencies

## Run
Open `index.html` in a browser or use VS Code Live Server.

## Testing
Test search, filters, sorting, save jobs, View & Apply, contact form and mobile navigation in Chrome, Edge and Firefox.
